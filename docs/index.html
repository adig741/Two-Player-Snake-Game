Three modes.
One more round.

03 / HOW TO PLAY

One keyboard.
Two contenders.

Grab a friend and claim your side of the keyboard. Each snake has its own set of keys, so the chase stays fast and personal.

↵After game over, press Enter to restart or Esc to return to level selection.
